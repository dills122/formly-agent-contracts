# Independent Review Packet: Typed Factory Input Analysis

The packet is split so a fresh reviewer can inspect the repository before
reading the author's interpretation:

1. Read [the neutral bootstrap](./review-bootstrap.md).
2. Inspect the frozen change and run read-only verification.
3. Only then read [the author explanation](./author-explanation.md).
4. Compare the author's claims with the evidence and record findings.

Review dispositions and reconciliation evidence are retained in
[`reviews/`](./reviews/README.md).
